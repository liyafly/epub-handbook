# fiction-en

适合源 XHTML 已明确标记为英文的小说页面。请先确认根元素有 lang=en，
正文容器有 english-fiction；本预设不推断语言、不修改标记，也不应用到
中文页面。英文段落左对齐并保留适度首行缩进，显式 en-noindent 仍保持顶格；
引用、场景分隔、插图与大字号测试段保留自然重排。

预设不锁正文字体。fonts.css 只提供可选的 font-en-serif 角色类；不下载字体，
也不自动启用浮动首字。建议只把预设作用到目标英文 spine 页面，先检查
dry-run 的目标与覆盖情况，再生成新候选并核对普通首段、大字号和长词折行。
当前没有对应真实阅读器验收记录。
