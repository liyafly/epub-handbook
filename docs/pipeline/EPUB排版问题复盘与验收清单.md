# EPUB 排版问题复盘与验收清单

本文是一次 EPUB 排版检查的匿名案例复盘，保留可复用的原因分析与验收建议，不新增仓库硬规则。书名、作者、正文内容、页码、内容 ID、私人路径、成品指纹、精确案例数量及本地恢复标识均不收录；具体证据保留在本地书级材料中。

本次复核了现有成品、Git 改动、脚本和验收材料，没有修改书稿，也没有重新进行全书原生阅读器验收。

## 结论

反复出现问题的主要原因，是此前没有查完同类问题，局部修复后验收范围没有跟上整本可读性的目标。处理过度围绕新截图逐处修补，随后又过早收窄检查范围，让用户不断发现遗漏。责任主要在代理的检查和收尾方式。

本案例没有发现版本回退的证据，不能把反复出现的遗漏归因于用户导入错误或阅读器缓存。图片、公式、表格存在不同的阅读器表现，浏览器和机械检查通过不足以证明实际阅读效果合格。

## 为什么反复出现

| 问题 | 本案例中确认的事实 | 此前遗漏 |
| --- | --- | --- |
| 小图片异常放大 | 基础样式让图和图片占满容器，不少小图只有内联 em 上限；Kindle 转换后的实际画面没有达到预期尺寸约束。 | 早期已经识别小图风险，后续却主要修复少数插图，其余同类位置继续沿用原规则。 |
| 连续公式留白过大 | 少数公式采用专用布局后改善，其他位置仍沿用原 MathML 显示方式；后续原生试验才确认了同类留白的处理方向。 | 未由局部修复推进到全部同类实例检查；浏览器间距正常，被赋予了超过其证明能力的信心。 |
| 表格分页反复修改 | 候选迭代先后遇到留白过大、末行拆页、后续长表拆页和跨阅读器分页不一致。 | 后续又修改了同章图片尺寸，可能影响分页流，但没有补齐当前候选的整章表格回归。属于验收缺口，尚不能据此断言已有新的断表。 |
| 检查很多，仍有明显问题 | 大量机器检查覆盖结构、引用、资源可用性及部分特定内容；浏览器探针主要发现溢出、丢图、零尺寸等问题。 | 没有充分衡量小图是否过大、公式是否过疏、图文节奏是否合理。结构通过和“没有新增问题”均不能代替版式验收。 |
| 当前状态容易误读 | 制作记录顶部仍指向旧成品，末尾才记录最新交付。 | 当前状态摘要未随交付同步，历史阶段与当前待办混在同一长文中。 |

上述阅读器现象属于本案例的已测候选，不能外推为所有 EPUB、MathML 或阅读器的通用兼容结论。

## 局部通过为什么没有形成完整验收

此前处理分别覆盖了少数公式、少量插图、指定章节表格和一组字符对照示例。各阶段确有局部改善，但没有形成覆盖全书同类位置的持续问题清单。

后来扩大了图片和公式修改范围，原生检查仍主要围绕指定截图组与代表页面。修改范围扩大，不等于验收范围已经同步扩大。

“每轮只处理少数目标”适合控制一次试验的规模，不能成为发现共性缺陷后停止检查其余实例的理由。局部试验收敛后，应回到全部受影响实例完成检查。

| 项目 | 已有证据能证明什么 | 不能据此宣称什么 |

| 指定原生画面 | 已保存截图完整，指定图片和公式画面有改善。 | 截图数量不能证明所有变更点已在各目标阅读器验收。 |
| 批量图片尺寸调整 | 已补充明确尺寸，指定位置比例改善。 | 尚未逐幅确认全部标签、节点、图注及相邻正文在普通和较大字号下可辨。 |
| 批量公式调整 | 指定位置留白改善，表达树保留。 | 尚未逐条确认全部复杂公式的留白、上下标、分数、矩阵及分页；保留表达树也不能证明原表达式语义正确。 |
| 特殊角色公式 | 专用位组、括注或竖式存在独立结构和样式。 | 不能因普通公式已修就跳过，也不能仅因仍使用块级显示就判为错误。 |
| 窄屏长公式 | 浏览器探针仍发现横向溢出，前后清单相同。 | “原有问题”不等于已经达到可读性目标，浏览器能横滚也不证明目标阅读器中可操作。 |
| 表格分页 | 旧候选已有指定配置的验收。 | 同章图片或相关布局发生变化后，不能直接把旧候选的通过转签到当前包。 |
| 当前状态文档 | 历史和最新交付记录均保留。 | 顶部摘要与最新交付不一致的问题尚未在本次复核中修正。 |

本次未重新证明实体设备、手机／平板显示、全部公式语义或 EPUBCheck CI；既有字体覆盖与外链激活待验项也没有因此清零。

## 后续验收建议

1. **先列全受影响实例。** 以稳定内容 ID 关联参考 PDF 位置、角色、现象、改动和待验配置。分别登记已确认缺陷、已修改待验、指定范围通过和未验证项，不能把缺少证据的位置当作通过。
2. **先验证机制，再完成同类检查。** 用最小候选确认处理方向；稳定后检查全部变更点。代表性抽样用于试验和未改动场景回归，不替代全部变更点的检查。
3. **以实际目标阅读器确认效果。** 优先在已暴露问题的模式验证普通与较大字号，再批量完成其他目标阅读器对应范围。以 PDF 核对内容关系和相对比例，同时允许重排版自然换行分页。
4. **把分页影响纳入回归。** 图片尺寸、公式高度或相关 CSS 变化时，连同相邻正文、说明段和表格一起检查。表格需实际看到表头、末行和前后文，不能仅依赖禁止拆分的样式声明。
5. **分开记录证据层级。** 机械检查、浏览器预检、指定原生画面和整本验收分别记录。原生证据应绑定内容 ID、候选指纹、实际阅读器版本与配置、截图和观察；这些具体绑定留在本地书级材料中。
6. **按依赖判断旧证据是否仍适用。** 包内成员全部一致时，可附等价证明引用既有证据；图片、字体、相关 CSS 或分页流变化时，应扩大对应回归。不得仅凭文件名相同沿用通过结论。
7. **完成当前候选的收尾。** 明确处理长公式、特殊公式和受影响表格的剩余清单；候选与正式包一致后，同步制作记录的当前基线、待办和证据入口。未解决或未验证项保留明确状态。

这些是后续工作建议。本次没有执行上述修复或验收，也没有修改仓库规范、技能或书级源文件。
