3. [Recipes](recipes.en.md): special effects you can copy, and how each reader handles them.
4. [FAQ](faq.en.md): find the cause from the symptom.
5. [Glossary](glossary.en.md): look up unfamiliar words.

Maintainers and AI tools: see [AGENTS.md](../../AGENTS.md) and the [maintainer index](../README.md) (Chinese).
