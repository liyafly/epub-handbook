# 术语表

[English](glossary.en.md) · [指南首页](README.md)

## EPUB 本身

- **EPUB**：一种电子书格式。本质是一个 zip 包，里面是 HTML（XHTML）、CSS、图片和目录。阅读器会按屏幕和字号重新排版，这叫**可重排**；本工具只处理可重排的书，不处理固定版式。
- **EPUB 2 / EPUB 3**：两个版本。看 OPF 里的 `<package version="2.0">` 或 `"3.0"` 区分。本工具面向 EPUB 3。
- **XHTML**：书的正文文件，语法比普通 HTML 严格。
- <a id="opf"></a>**OPF**：书的清单文件（常叫 `package.opf`），写着书名作者、包含哪些文件、按什么顺序读。
- <a id="manifest"></a>**manifest**：OPF 里登记全部文件的部分。没登记的文件阅读器看不到。
- <a id="spine"></a>**spine**：OPF 里规定阅读顺序的部分。
- <a id="navxhtml"></a>**nav.xhtml**：EPUB 3 的目录文件。
- <a id="ncx"></a>**NCX**：EPUB 2 的目录文件。为了照顾 Kindle 和旧阅读器，通常两个都留。
- **`epub:type`**：给元素加语义的属性，例如 `epub:type="footnote"`。用之前要在 `<html>` 上声明 `xmlns:epub`。
- **弹注**：点一下注释号，注释在原地弹出小窗，不用跳走。
- **DRM**：商店加在书上的加密。本工具遇到就停下，不解密。

## 字体

- **嵌入字体**：打包进书里的字体文件。阅读器允许时会用它显示。
- **字体母版**：完整的原始字体文件，放在共享字体库 `fonts/` 里，`book.json` 用 SHA 锁定版本。
- **子集**：只保留书里用到的字的字体，体积小得多。构建时从母版自动生成。

## 本工具

- **书目录**：一本书的工作文件夹，里面有 `book.json`、`original.epub`、`epub/`、`out/`，见 [快速开始](quick-start.md#2-认识书目录)。
- **回退 / 增强**：先写所有阅读器都能显示的写法（回退），再写支持的阅读器才生效的效果（增强）。增强失败时书仍然可读。
- **配方**：一种特殊效果的可复制 CSS 和样例，见 [配方](recipes.md)。
- **预设**：一整套适合某类书的样式，只在建新书时用一次。
- **阅读器版本 / 叠加层**：给某个阅读器单独出的版本，只能替换 CSS 和 OPF，正文与通用版相同，见 [阅读器](readers.md#一份源多个阅读器版本)。
- **红线**：打包前后必须不变的东西：正文、元数据、阅读顺序、锚点、封面和加密状态。用 `epub redline` 检查。
- **导航审计**：检查包结构、目录和注释链接是否可用，也检查字号有没有被锁死。
- **收据**：构建成功后记下的成品 SHA，存在 `.epub/` 里。成品被手动改过时，构建会据此拒绝覆盖。

## 阅读器相关

- **Send to Kindle**：亚马逊的送书服务，在云端把 EPUB 转成 Kindle 格式。
- **Kindle Previewer**：亚马逊的桌面预览工具，只是近似，结果以设备为准。
- **KFX / AZW3**：Kindle 自己的格式。本工具不直接生成它们。
