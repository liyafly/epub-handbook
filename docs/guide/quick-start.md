# 快速开始

[English](quick-start.en.md) · [指南首页](README.md)

从一本现成的 EPUB 开始，十分钟内做出第一个改好的版本。没装 `epub` 的话，先看 [安装](../../README.md#安装)。

## 1. 导入

```sh
epub book import 原书.epub 我的书
```

这一步会：

- 把原书复制成 `我的书/original.epub`，设为只读，SHA 写进 `book.json`；
- 检查包结构和目录。遇到 DRM、加密或损坏的文件就停下，不会尝试解密；
- 把书解包到 `我的书/epub/`，加一个空的 `reader.css`（在每一章里最后加载，做阅读器版本时只替换它）；
- 如果书里嵌了完整字体，把它们移到共享字体库 `fonts/`（沿上级目录找已有的；没有就在书目录旁新建），`book.json` 用 SHA 锁住版本。看起来已经子集化的字体留在原处。这一步需要 [字体工具](../../README.md#安装)。

导入停下时，`original.epub` 和检查报告都会保留，方便查原因。常见情况见 [常见问题](faq.md#导入)。

想从零写一本新书，用 `epub book new 我的书`；加 `--from-preset literary-cn` 可以用某个书型预设作起点。

新书自带纯色占位封面 `epub/OEBPS/Images/cover.png`、版权页 `Text/00-copyright.xhtml` 和隐藏的导览（landmarks）。换封面时用同名 PNG 覆盖即可；换成 JPEG 的话，同时把 `package.opf` 里封面那一项的 `href` 改成新文件名、`media-type` 改成 `image/jpeg`。

## 2. 认识书目录

```text
我的书/
  book.json       # 唯一的配置：书名、成品文件名、字体、阅读器版本
  original.epub   # 冻结的原件，只读，不要改
  epub/           # 解包后的书，唯一要编辑的地方
  out/            # 成品，build 成功后才出现
  .epub/          # 隐藏：检查报告、成品收据、预览、失败现场；可以清理
  制作说明.md     # 一屏长的提纲：状态、目标阅读器、配方、待办
  素材/           # 自己建：要长期留的脚本、源图、验收截图、修改经过（历史.md）
```

你只需要改 `epub/`，偶尔改 `book.json` 和 `制作说明.md`。`.epub/` 随时会被清理，要留的东西放 `素材/`。

## 3. 预览

```sh
epub book preview 我的书 --open
```

预览会打包一份 `.epub/preview.epub` 并用系统默认程序打开。在 Mac 上建议指定 `--open=Reeden`：默认程序通常是 Apple Books，它每次导入都会多一份副本，适合留到最后验收。

预览很快，因为它**不做任何检查**，也不碰 `out/`。它只用来看效果，不能拿去交付。

## 4. 改样式

样式表在 `epub/OEBPS/` 下的某个文件夹里（导入的书沿用原来的位置，新书在 `Styles/`）。每次只改一处，改完再预览。

- 想要现成的效果，从 [配方](recipes.md) 复制。
- 字号用 `em` 或 `%`，图片宽度用 `%`。不要在 `html` 或 `:root` 上写 `font-size`，否则有的阅读器调不了字号，构建也会拦下来。
- 不要给整页固定文字色和底色，这样夜间模式才能正常工作。

正文文字不要改。构建会检查正文是否和原来一致。

## 5. 构建

```sh
epub book build 我的书
```

构建会依次做下面这些检查，任何一项不过就停下。终端里每项检查一行，`PASS` 表示通过：

| 检查 | 含义 |
| --- | --- |
| 字体注入 | 按 `book.json` 里的 SHA 从共享库取字体，文件不对就停 |
| 字体子集 | 只保留书里用到的字，并确认没有因此丢字。原字体本来就缺的字只警告，不阻断 |
| 角色字体 | 列出指定了字体的文字（书信、标题、锁定的正文等）里，指定字体没有的字。只警告，因为回退字体可能显示正常，要在多个阅读器里实际查看 |
| 导航审计 | 包结构、目录、注释链接可用，字号没有被锁死 |
| 红线 | 打包前后的正文、元数据、阅读顺序、锚点、封面和加密状态都没变 |
| Kindle 检查 | 一行列出 Kindle 静态检查的 error、warn、info 数量，明细在 `report.html`。只提示；只有名为 `kindle` 的版本遇到 error 才停 |
| 正文对比 | 每个阅读器版本的正文都和通用版逐字一致 |
| 成品收据 | 记下 `out/` 里每个文件的 SHA，防止以后误覆盖你手动改过的成品 |

`WARN` 是不阻断的提醒，例如字体缺字（只算正文里真正用到的字）或成品超过 50 MB（Send to Kindle 可能拒收）。最后一行 `INFO` 和上一次成品对比，只供参考。全部结果汇总在 `.epub/report.html`，用浏览器打开即可。

任何一项失败，`out/` 里的文件都不会变。失败现场留在 `.epub/build.*`，`epub book clean 我的书` 会清掉旧的现场，只留最近一次。

## 6. 送到阅读器

成品在 `我的书/out/`。默认是 `book.epub`，配置了阅读器版本的还有 `book-kindle.epub` 这样的文件。怎么送、要注意什么，见 [阅读器](readers.md)。

## 构建拒绝覆盖成品时

如果你直接改过 `out/` 里的 EPUB（比如用 Calibre 或 Sigil 修了一处），下次构建会拒绝覆盖它，并提示 `Refusing to overwrite dist`。这是为了不悄悄丢掉你的修改。有两种处理方法：

- **不要那些修改**：删掉 `out/` 里的那个文件，重新构建。
- **要保留修改**：先把同样的修改做进 `epub/`，再运行 `epub book accept-dist 我的书`。它会用 `epub/` 重新构建，确认每个文件都和 `out/` 里的完全一样，然后才重新记下收据。

## 其他命令

| 命令 | 用途 |
| --- | --- |
| `epub book fonts 我的书` | 把完整字体放进 `epub/`，方便在编辑器里预览字体 |
| `epub book fonts 我的书 --update-lock` | 换了字体母版之后，确认无误再更新 SHA 锁 |
| `epub book build 我的书 --variant kindle` | 只构建一个阅读器版本 |
| `epub book import … --git` | 在书目录里建一个独立 Git 仓库（可选） |
| `epub book reader-layer 我的书` | 给还没有 `reader.css` 的旧书补上它 |
| `epub book add-chapter 我的书 --title 第二章` | 加一章，同时登记到 OPF、目录和 NCX；`--after 01-chapter.xhtml` 插在某章之后 |

省略书目录时，命令作用于当前目录。用旧版目录结构（`03 制作工作区/`）的书也用这些命令，工具会自动识别。
