# 使用指南

[English](README.en.md)

给想把自己的 EPUB 排得更好看的普通读者。按顺序读，每页几分钟。

1. [快速开始](quick-start.md)：导入、预览、改样式、构建，以及构建拒绝时怎么办。
2. [阅读器](readers.md)：Apple Books、Kindle、Reeden 各自要注意什么，怎样给不同阅读器出不同版本。
3. [配方](recipes.md)：可以直接复制的特殊效果，以及它们在各阅读器上的表现。
4. [常见问题](faq.md)：按现象查原因。
5. [术语表](glossary.md)：遇到不懂的词来这里查。

维护者和 AI 工具请看 [AGENTS.md](../../AGENTS.md) 和 [维护者文档索引](../README.md)。
